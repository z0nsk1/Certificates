Tässä repossa on Mimo-sovelluksessa ja Coursera:ssa suorittamani sertifikaatit sekä Full Stack Mooc -kurssin sertifikaatti. Mimo on samantyylinen kuin Duolingo, mutta siellä on Web-ohjelmoinnissa käytettäviä teknologioita, kuten JavaScript, Python ja HTML. Coursera on verkkokursseja tarjoa alusta, jossa organisaatiot, kuten Microsoft ja IBM voivat tarjota kurssejaan kelle tahansa suoritettavaksi. Sertifikaatteja olen suorittanut ylläpitääkseni taitoja ja toisaalta myös näytöksi osaamisesta. <br><br>

<strong>In English</strong><br>
In this repository are certificates I have completed in Mimo and Coursera and my Full Stack Mooc course certificate. Mimo is like Duolingo, but it is about most common Web-programming technologies, like JavaScript, Python and HTML. Coursera is a platform offering online courses, where organisations like Microsoft or IBM can offer their courses for anyone to complete. I have completed these certificates to maintain my coding skills and also to prove those skills.
